Вариант 8. Отдел доставки торговой фирмы «Индигирка»

# Триггер 1:
При добавлении новых коробов в путевой лист ТС необходимо убедиться, что суммарная масса всех коробов не превышает грузоподъемность ТС. Если превышает, то необходимо вывести ошибку и сообщить насколько превышает.
 
# Триггер 2:
После проставления отметки об оплате заказа, добавление, изменение или удаление коробов в заказе или изменение информации о составе коробов недопустимо и должно возвращать ошибку.
 
# Процедура 1. Оформление путевого листа по нескольким заказам.
Процедура предназначена для оформления путевого листа ТС для нескольких заказов. Процедура принимает список id заказов, которые необходимо доставить и создает новый путевой лист для ТС, которое сегодня свободно. Если суммарная масса заказов превышает грузоподъемность ТС, то создается несколько путевых листов на следующие дни для этого ТС. А заказы при этом распределяются по разным путевым листам. При этом короба из одного заказа могут быть доставлены в разные дни, но сам короб при этом разделен быть не может.
 
# Процедура 2. Оформление заказа.
Процедура предназначена для оформления заказа. Процедура принимает список значений (id товара, кол-во, пункт доставки), создает заказ на доставку и распределяет товар по коробам в соответствии с пунктами доставки. При этом вес короба не должен превышать 40 кг.
